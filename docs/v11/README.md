## 再開分（2026-11-11）

- **月表示（MONTH-041/065）**: 行をタップした瞬間に切り替わる一覧をやめ、給与・支払いと同じ月ホイール（下書き→「この月を表示」で確定、「閉じる」で元のまま）へ統合。
- **分析グラフのなぞり（HOME-010・MONTH-046・MONTH-051 ほか）**: 棒グラフと折れ線グラフを指でなぞると、その位置の項目と金額を下に表示。左右の矢印キーでも同じ操作ができ、読み上げ用に同じ値の表を持つ。表示だけで保存しない。遷移先にグラフが無い分析（理由の分析・給与分析など）は対象外。
- **電卓の⌫長押し（CALC-124）**: 押し続けると連続で消え、指を離すと止まる。
- **カード請求の月見出しスワイプ（SALARYEDIT-191/192）**: 今日・今月と同じ共通のスワイプ処理を使う補助操作。矢印ボタンが主。
- **ACFの安全予算を日別計画へ反映（ACF-257）**: 何日分を反映したか、反映する金額が無いか、失敗したかを必ず表示（以前は何も起きないように見えることがあった）。
- **動き**: push 220ms・シート260ms・メニュー160ms・状態変化150〜220ms を `tokens.css` の値で統一。タブの選択表示（420ms）、シート（280〜300ms）、グラフの描画（550〜620ms）、ACFの強調（280〜420ms）、行の並べ替え（300〜360ms）を短縮し、注意を引く無限の点滅は1回の強調にした。仕様外の長さを入れると `npm test` が失敗する。
- **不具合の修正**:
  - 月間目標の承認後の「月カレンダーで日別計画を見る」（GOAL-031）が、今月のカレンダーではなく今日の画面に戻っていた。今日／今月の切替を導入する前の書き方が残っていたため。共通の切替処理を使うよう直した。
  - カテゴリのアイコン選択の読み上げ名を「食事」「電車」などの日本語名にした（前回は内部名だった）。
- **入口がメニューへ移っていた操作**: 以前の画面整理で、今日・今月の画面の「メール取引」の行（HOME-012・MONTH-050）、今月の「大型支出計画」の一覧（LARGE-069）、今月の「今月の収入」の欄（SIM-270）は画面から外れ、同じ機能が今日のメニュー・支払いタブ・支払いの追加メニュー・給与タブから使える。画面を作り直さず、移った先の入口で検証した（`remaining-ops.csv` の備考）。
- **文字**: 11px未満の文字（98箇所）を最小値 `--type-min: 11px` へ。幅340px以下の月タイトルを22pxにして右のボタンと重ならないようにした。

## CSSの再構成

版ごとに上書きを重ねていた16ファイル（`00-base.css`〜`workspace.css`、`v11-components.css`）を廃止し、部品ごとの16ファイルへ作り直しました。

| 項目 | 数 |
|---|---|
| 元の規則／セレクタ単位の項目 | 2,302／2,578 |
| どこからも使われていないクラスの規則を削除 | 174項目（85クラス。一覧は `css-restructure-stats.json`） |
| 後の規則に上書きされて効いていなかった宣言を削除 | 486 |
| 同じセレクタの規則を1つに統合 | 202 |
| 出力の規則数 | 2,028 |

方法（`scripts/v11/css-restructure.mjs`）：全規則をセレクタ単位に分解し、同じ要素・同じ優先度で競合しうる規則の組だけ元の前後関係を制約として保ちながら、統合と並べ替えを行いました。競合の判定には、巡回で観測した要素のクラスの組と、スクリプト中の class 属性の記述を使っています。

検証：旧ビルドと新ビルドに同じ操作を行い、全要素（疑似要素を含む）の算出スタイルを比較しました。幅393ライト・幅320ダークの各550状態、各約30万要素で**差分0件**です。この比較のあとに、第11版の修正（文字階層、44pt、新しい部品）を各セレクタの規則そのものへ反映しています（`scripts/v11/css-edition11-edits.mjs`）。

残っている点：
- 統合すると他の規則との優先順位が変わるため、同じセレクタの規則が2か所に分かれたままのものが68あります。
- 優先順位を保つために、本来の部品とは別のファイルに置いた規則が843あります（主に `base.css`）。ファイル名は部品を表しますが、分類は完全ではありません。
- 旧構成で詳細度を上げるために使われていた `#app` 付きのセレクタは、そのまま残しています。
- 比較はホバー・押下中・フォーカス中の状態、および巡回で到達しなかった画面を含みません。
