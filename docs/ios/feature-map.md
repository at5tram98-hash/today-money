## Web 版に無い、iPhone だけの機能

| 機能 | 内容 |
|---|---|
| ウィジェット | ホーム画面（小・中：今日あと使える額・ACF・次の支払い・「支出を入力」ボタン／中・大：これからの支払い・今月の支出・総資産）、ロック画面（丸・長方形・1行）。日付が変わると自動で切り替わる |
| コントロールセンター | 「支出を入力」ボタン（iOS 18 以降。ロック画面のボタンにも置ける） |
| Siri・ショートカット | 「My Moneyで支出を記録」（金額・カテゴリ・店名・支払い方法）、「My Moneyで今日あと使える額」、「My Moneyで次の支払い」、「My Moneyで○○を開く」。設定なしで Siri・Spotlight・ショートカットから使える |
| アイコン長押しメニュー | 支出を入力（今日の残りを表示）・日締め・ACF・メールの確認（確認待ちがある時） |
| 元に戻す | 保存・削除のあとに出る知らせから、直前の変更を取り消せる |
| 資産 | 現金・預金・直近30日の増減と％・口座の割合（ドーナツ）・資産推移（実績／ACF予測、1W〜全期間、なぞると日付と残高）・期間の変化・最高・最低・口座一覧（並べ替え・30日の推移・増減）・残高履歴・資金計画へのリンク | Web 版と同じ数字（AssetsCompatTests） |
| 口座の詳細 | 期間（1週間〜1年）の推移・入金／出金・自由に使える額・60日の引落準備（最低予測残高・不足日・予定）・この口座の動き | Web 版と同じ数字（AssetsCompatTests） |
| 給与 | 月の受取見込み・前月比・入金済み／これから／未確認の帯・勤務先別の構成（ドーナツ・割合は合計100%）／給与推移（1M〜全期間・なぞると金額）・次の入金・勤務先（6か月の推移・割合）・給与記録・振り分け・臨時収入・給与分析 | Web 版と同じ数字（SalaryDashboardCompatTests） |
| ハイライト | 支出のペース・1日の平均・いちばん多いカテゴリ・収入と支出（文と2本の棒、押すと詳しい画面へ） | Web 版と同じ文（HighlightCompatTests） |
| 月間詳細分析 | 日別の支出と目標（なぞると金額）・計画と実績・過去3か月（前月比・前年同月比）・カテゴリの割合と増減・高額支出 TOP5・急に増えたカテゴリ | Web 版と同じ数字（MonthAnalysisCompatTests） |
| 一覧の操作 | 取引：左へスワイプで削除・右へスワイプで「今日もう一度」・長押しでプレビューとメニュー。メール：スワイプで反映／対象外。大型支出：スワイプで支払った／削除。メール・カレンダーは引っぱって更新 |
| 起動画面 | アプリの色とコインの起動画面（ダークモード対応） |
| 文字の大きさ | 端末の文字サイズ設定に合わせて金額も大きくなる |
