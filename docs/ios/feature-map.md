# 機能対応表（Web 版 ↔ iOS 版）

凡例：✅ 移した ／ 🟡 一部 ／ ⬜ まだ（Web 版で使う）

| 分類 | Web 版の機能（主なファイル） | iOS 版 | メモ |
|---|---|---|---|
| 画面構成 | ホーム／支払い／その他の3タブ・右下の「＋」・検索 | ✅ | `RootView`。「＋」を長押しすると種類を選んで開ける |
| データ | 1つの JSON に全部保存・バックアップ／復元・全削除（00-data-model, 01-storage, 13-settings-and-backup） | ✅ | SwiftData に同じ JSON を保存。未知の項目も保つ。復元ポイント20件。全削除は「削除」と入力 |
| 初期データ | 初回起動の値（勤務先・口座・カードなど） | ✅ | `Resources/first-run.json` |
| 起動時の処理 | 支払日が来た固定支払いの記録・口座への反映（processScheduled） | ✅ | 起動時と画面に戻った時。照合済みの規則で反映 |
| ＋ 新規入力 | 支出・臨時収入・残高・給与・カード請求の5種類、電卓、カテゴリ、最近、支払い方法、日付、店名（ios-native: openEntryCalc） | ✅ | 左右になぞると種類が変わる。「予定」から固定支払い・大型支出 |
| 支出 | 記録・編集・削除・返金、口座／デビットの残高反映と取消（08-transactions） | ✅ | 照合テスト（MutationCompatTests） |
| 取引一覧 | 月・日・検索・カテゴリで絞り込み（openTransactionList） | ✅ | スワイプで削除 |
| ホーム | 支出（今日／今月・日付の切替・目標）・総資産・今月の給与・次の支払い・ハイライト・最近の動き・今月の比較・大型支出（home-v14） | ✅ | |
| 日締め | 7ステップ（日締め → 収入 → メール取引 → 普通取引 → 銀行残高 → 承認 → 承認されました）・直近7日・18:00以降・確認待ちメールは承認不可・承認後の変更検知・修正・取消（理由と「取消」入力）・日締めジャーナル（day-closing） | ✅ | 承認の署名は Web 版と1文字も違わない（ClosingGoalCompatTests）。Web 版で承認した日は iOS でも承認済、その逆も |
| 目標 | 当日目標（金額 → カテゴリ → 確認）・月間目標（おすすめ → 大型支出 → 日常予算 → カテゴリ → 日別計画 → ACF安全確認 → 確認）（11-home-and-month の goalPlanner） | ✅ | おすすめ額・カテゴリ配分・日別の配分・固定日・他の日で合わせる・同じ曜日／平日／週末に適用・ACFに合わせて最適化・保存の形は Web 版と同じ（照合テスト） |
| 支払い | 月の「これから支払う額」・前月比・次の引落・カード一覧（推移）・固定支払い・大型支出・デビット（19-payments-and-atf） | ✅ | 照合テスト（LedgerCompatTests） |
| カード | 締め日・引落日・請求月の計算・確定後の利用・予定の加算（固定支払い・必須の大型支出） | ✅ | 照合テスト |
| カード | 詳細（支払月ごとの請求・対象期間・明細・カテゴリ別）・請求額の確定／修正・支払済み（残高反映の選択）・未払いに戻す | ✅ | |
| 固定支払い | 登録・編集・削除・毎月／隔月／毎年・今回はとばす・記録 | ✅ | |
| 大型支出 | 計画・必須／検討中・分割払い・延期／中止・「支払った」で支出に | ✅ | |
| 口座とカード | 銀行口座・クレジットカード・デビットの追加／編集／削除／並べ替え、使用中は削除しない | ✅ | |
| カテゴリ | 追加・編集（色・アイコン）・削除・並べ替え・名前変更で支出も追従 | ✅ | |
| 初期データ・現在値 | 銀行残高・今月支払うカード請求 | ✅ | |
| 給与 | 月の給与・勤務先ごと・給与の追加／編集／削除・入金済み | ✅ | |
| 臨時収入 | 記録・受け取った（口座に反映）・編集・削除 | ✅ | |
| 勤務先 | 時給・交通費・休憩ルール・別名 | ✅ | 追加・締め日／給料日の変更は Web 版 |
| シフト | 貼り付けで取り込み・自動取り込みの規則 | ✅ | |
| シフト | iPhone のカレンダーから取り込む（1日1回の自動・今すぐ・読むカレンダーの選択・予定名のキーワード・対象外の予定の表示）（shift-import の Google カレンダー、salary-v18 のショートカット経由） | ✅ | EventKit で直接読むので、Google のログイン・受け渡しサーバー・ショートカットは不要。給与の作り方は Web 版の applyShiftsAuto と同じ（同じシフトで Web 版と金額一致を確認）。カレンダーを変更しない |
| ACF | 今日使える目安（現金／カード）・日別資金表（表・カレンダー・重要日のみ）・残高予測・生活費目安のグラフ・重要な資金イベント・計算内訳・注意点・予測の信頼度・C100モード（04/05/17-acf-*, acf-calendar） | ✅ | 計算は Web 版と同じ（AcfCompatTests：9通りの設定で全行一致） |
| ACF | ACF指標（使えるお金と予定の支払いの比・期間の終わりの日）（26-liquid-v16, salary-v18） | ✅ | ホームのカードと詳細 |
| ACF | ACF設定（最低残高・カード利用・比率・リアルタイム試算・1日上限・優先カード・使っていい場所・曜日傾向・必須の大型支出） | ✅ | |
| ACF | 購入前シミュレーション・安全予算を日別計画へ反映 | ✅ | |
| ACF | 支払いタブの ATF（初期データ専用の旧い試算 mm3AtfBuildForecast） | — | 期間が 2026-11-30 に固定された試算のため、iOS では ACF に置き換えた |
| ACF | 予測リスクの通知 | ⬜ | 設定は保存する。通知の送信はまだ |
| 通知 | 記録のリマインド・引落の前日・給料日 | 🟡 | Web Push の代わりにローカル通知。目標・残高低下は画面内のお知らせ |
| お知らせ | システムのお知らせ（今日の分） | ✅ | |
| 外観・ロック | 外観（システム／ライト／ダーク）・パスコード | ✅ | パスコードは Face ID／端末のパスコードに置き換え。離れた時のぼかし |
| 一般 | 起動時の画面・週の始まり | 🟡 | 設定はあるが、起動時の画面の切り替えはまだ反映していない |
| メール | Gmail からの取り込み・明細の照合（14-gmail, 23-statement-import-and-review） | ⬜ | Google ログインが必要（着手前に確認） |
| 分析 | Pro 分析・月の振り返り・お気に入り・タグ・旅行やプレゼントの計画（15-pro-features, eventGoals） | ⬜ | データは保持（Web 版で使える） |
| その他 | PDF 書き出し・操作音と触覚の設定 | ⬜ | 触覚は標準のものを使用 |
