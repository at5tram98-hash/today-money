# 機能対応表（Web 版 ↔ iOS 版）

凡例：✅ 移した ／ 🟡 一部 ／ ⬜ まだ（Web 版で使う）

| 分類 | Web 版の機能（主なファイル） | iOS 版 | メモ |
|---|---|---|---|
| データ | 1つの JSON に全部保存・バックアップ／復元（00-data-model, 01-storage, 13-settings-and-backup） | ✅ | SwiftData に同じ JSON をそのまま保存。未知の項目も保つ。読み込み・書き出し・復元ポイント |
| 初期データ | 初回起動の値（勤務先 GU・無印良品、口座など） | ✅ | `Resources/first-run.json`（Web 版の初期値を書き出したもの） |
| ホーム | 今日の支出・今月の支出 | ✅ | 目標があれば「あと使える額」 |
| ホーム | 総資産（口座の合計） | ✅ | 口座の一覧 |
| ホーム | 今月の給与・次の給料日 | ✅ | |
| ホーム | ACF 指標・次の支払い・ハイライト（26-liquid-v16, home-v14） | ⬜ | ACF の計算（04/05-acf-*）は次の段階 |
| 給与 | 月の給与（受取見込み・入金済み・これから・未確認・前月比） | ✅ | 予定の入金日の月にまとめる（第19版の修正と同じ） |
| 給与 | 勤務先ごとの内訳・給与記録の一覧 | ✅ | |
| 給与 | 給与の編集（金額・入金済み・実際の入金日） | 🟡 | 入金の記録（収入・口座への反映）とつながった給与の入金状態は Web 版で変更 |
| 給与 | 給与の追加・削除、給料日の振り分け、臨時収入の追加、給与分析 | ⬜ | 臨時収入は一覧に表示のみ |
| 勤務先 | 時給・交通費（1勤務／月額）・上限・休憩ルール・予定名（別名） | ✅ | 計算例つき |
| 勤務先 | 勤務先の追加・締め日／給料日の変更 | ⬜ | 表示のみ |
| シフト | 貼り付けで取り込み・休憩・深夜割増・交通費（1日1回）・上限 | ✅ | 計算は Web 版と同じ（照合テスト） |
| シフト | ショートカット → 受け渡しサーバー → 1日1回自動（salary-v18, worker） | ⬜ | iOS 版では今後、iPhone のカレンダー（EventKit）から直接読めるので、受け渡しサーバーは不要にできる |
| シフト | 手入力は7日間優先・消えた月の給与予定を消す | ✅ | 自動取り込み（`ShiftSync`）の規則として実装・照合済み |
| 支払い | カード請求・固定支払い・大型支出・デビット・支払い一覧（19-payments-and-atf, home-v14） | ⬜ | |
| 入力 | ＋（支出・収入・振替の電卓、5つのモード）（calculator, 08-transactions） | ⬜ | |
| 支出 | 今日・今月の画面、カテゴリ、グラフ（11-home-and-month, glass-v15） | 🟡 | 今日の一覧のみ |
| 計画 | 1日／月の目標・計画づくり（16-analysis-and-goals） | 🟡 | 目標の表示のみ |
| ACF | 資金見通し・安全残高・カレンダー（04/05/06-acf-*, 17-acf-refinements, acf-calendar） | ⬜ | |
| 日締め | 一日の記録の照合（day-closing） | ⬜ | |
| メール | Gmail からの取り込み（14-gmail, 23-statement-import-and-review） | ⬜ | Google ログインが必要（着手前に確認） |
| 通知 | Web Push（web-push, worker） | ⬜ | iOS ではローカル通知に置き換える予定 |
| 検索 | 取引の検索（glass-v15） | ⬜ | |
| 設定 | パスコード・見た目・音と振動・PDF 書き出し（settings, 13-settings-and-backup） | ⬜ | パスコードは Face ID に置き換える予定 |
