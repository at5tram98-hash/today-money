# 機能対応表（Web 版 ↔ iOS 版）

凡例：✅ 移した ／ 🟡 一部 ／ ⬜ まだ（Web 版で使う）

| 分類 | Web 版の機能（主なファイル） | iOS 版 | メモ |
|---|---|---|---|
| 画面構成 | ホーム／支払い／その他の3タブ・右下の「＋」・検索 | ✅ | `RootView`。「＋」を長押しすると種類を選んで開ける |
| データ | 1つの JSON に全部保存・バックアップ／復元・全削除（00-data-model, 01-storage, 13-settings-and-backup） | ✅ | SwiftData に同じ JSON を保存。未知の項目も保つ。復元ポイント20件。全削除は「削除」と入力 |
| 初期データ | 初回起動の値（勤務先・口座・カードなど） | ✅ | `Resources/first-run.json` |
| 起動時の処理 | 支払日が来た固定支払いの記録・口座への反映（processScheduled） | ✅ | 起動時と画面に戻った時。照合済みの規則で反映 |
| ＋ 新規入力 | 支出・臨時収入・残高・給与・カード請求の5種類、電卓、カテゴリ、最近、支払い方法、日付、店名（ios-native: openEntryCalc） | ✅ | 左右になぞると種類が変わる。「予定」から固定支払い・大型支出 |
| 支出 | 記録・編集・削除・返金、口座／デビットの残高反映と取消（08-transactions） | ✅ | 照合テスト（MutationCompatTests） |

| ホーム | 支出（今日／今月・日付の切替・目標）・総資産・今月の給与・次の支払い・ハイライト・最近の動き・今月の比較・大型支出（home-v14） | ✅ | |
| ホーム | 日締め（day-closing） | ⬜ | |
| 目標 | 月の目標と1日の目標（月から自動配分 or その日だけ） | 🟡 | Web 版の多段階の計画づくり（16-analysis-and-goals のウィザード）とカテゴリ別の目標はまだ |

| カード | 締め日・引落日・請求月の計算・確定後の利用・予定の加算（固定支払い・必須の大型支出） | ✅ | 照合テスト |
| カード | 詳細（支払月ごとの請求・対象期間・明細・カテゴリ別）・請求額の確定／修正・支払済み（残高反映の選択）・未払いに戻す | ✅ | |
| 固定支払い | 登録・編集・削除・毎月／隔月／毎年・今回はとばす・記録 | ✅ | |
| 大型支出 | 計画・必須／検討中・分割払い・延期／中止・「支払った」で支出に | ✅ | |
| 口座とカード | 銀行口座・クレジットカード・デビットの追加／編集／削除／並べ替え、使用中は削除しない | ✅ | |
| カテゴリ | 追加・編集（色・アイコン）・削除・並べ替え・名前変更で支出も追従 | ✅ | |

| 給与 | 月の給与・勤務先ごと・給与の追加／編集／削除・入金済み | ✅ | |
| 臨時収入 | 記録・受け取った（口座に反映）・編集・削除 | ✅ | |
| 勤務先 | 時給・交通費・休憩ルール・別名 | ✅ | 追加・締め日／給料日の変更は Web 版 |
| シフト | 貼り付けで取り込み・自動取り込みの規則 | ✅ | |
