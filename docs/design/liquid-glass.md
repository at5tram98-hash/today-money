# Liquid Glass の仕上げ（参考動画の分析と反映）

参考動画（iPhoneの画面収録・約62秒）を1秒ごとのコマに分けて確認した。分析結果と、このアプリへの反映箇所をまとめる。
動画の内容（他社アプリの画面）は転載しない。反映はすべてこのアプリの部品・配色・文言で行っている。

## 動画から読み取った特徴

| # | 特徴 | 動画での見え方 |
|---|---|---|
| 1 | 浮いたタブバー | 画面幅いっぱいではないカプセル。選択中のタブは淡いガラスのつまみ。内容がタブバーの下まで流れ、ガラス越しに透ける |
| 2 | 大見出しの切替 | 上端の大きな見出しが、スクロールすると中央の小さな見出しに切り替わる。境界線は無く、上端は内容をぼかしてなじませる |
| 3 | 上部の色のにじみ | 最初の画面だけ、見出しの背後に淡いグラデーション。スクロールすると消える |
| 4 | 丸いガラスのボタン | 戻る（‹）・閉じる（×）・追加（＋）・プロフィールが44pt前後の丸いガラス |
| 5 | カードの見出し | 見出しはカード内の左上に色つきのアイコン＋ラベル、右上に時刻と ›。下に大きな数値と小さな単位、右に小さなグラフ |
| 6 | グループの見出し | 「ピン留め」「ハイライト」のような太字の大きい見出し＋右に「編集」などのリンク |
| 7 | シート | 角の大きいシートが下から上がり、背後の画面は少し縮んで奥へ下がる。左上は丸い × |
| 8 | セグメント | 日／週／月などはガラスの溝に白い光沢のつまみ。押すとつまみが滑る |
| 9 | 動き | 押すと縮む・離すとばねで戻る。画面遷移は横に滑る |

## このアプリへの反映（`src/css/liquid-glass.css` ほか）

| # | 反映 | 実装 |
|---|---|---|
| 1 | タブバーは浮いたガラスのカプセル。内容はタブバーの下までスクロールし、ガラス越しに透ける。＋は第14版 Q-001（画面右下・タブの上・48〜52pt）を優先して位置と大きさを変えず、青の色つきガラスに。動画のようにタブバーの右隣へ並べる案は Q-001 と食い違うため採らない | `.tabbar`・`.add-hub`・`#app .screen { bottom: 0 }` |
| 2 | 少しスクロールすると上端がぼかしのガラスになり、境界線の代わりにぼかしで内容となじませる。見出しの高さ分スクロールすると大見出しが消え、中央に小見出しが出る | `24-accessibility.js` の `syncScrolled`（`native-scrolled`／`lg-collapsed`、`data-compact-title`） |
| 3 | ホームの上部だけ青・水色・紫の淡いにじみ。スクロールで消える | `#screen-today::before` |
| 4 | 専用画面（今日の支出・給与など）とpush画面の戻るを丸いガラスの ‹ に。見出しは中央。読み上げ名（「ホームに戻る」など）は従来どおり | `.detail-back`・`.push-nav .back-btn` |
| 5 | ホーム・支払いのカードの見出しをカード内の色つきラベルに（支出=橙、総資産=青、給与=緑、生活費の見通し=水色、次の支払い=紫、支払予定=紫、次の引落=赤）。右上に ›。今日／今月の切替もカード内の右上へ | `.home-card-wrap > .home-card-title` |
| 7 | シートを開くと背後の画面が少し縮んで奥へ（動きを減らす設定では行わない）。シート上部の「キャンセル」「保存」はガラスのカプセル（保存は青の色つき） | `body:has(> #sheet.show) #app`・`.sheet-nav .nav-text` |
| 8 | 今日／今月の切替はガラスの溝＋光沢のつまみ | `.home-period` |
| 9 | ＋・戻る・シートのボタンは押すと縮み、ばねで戻る | 各 `:active` |

## 画面準備中の表示（見直し）

| 以前 | 見直し後 |
|---|---|
| 画面中央の白いカードに、回る四角と横線。何の画面が出るのか分からない | **読み込み中**: ホームと同じ形のスケルトン（見出し・丸いボタン・色つきラベルのカード4枚・タブバー・＋）に光沢が流れ、下に小さなガラスの状態表示（12本のスピナー＋「データを読み込んでいます…」など）。読み込みが終わるとスケルトンが消えて本物の画面に切り替わる（0.3秒で薄く消える） |
| 計算中も同じ白いカード | **計算中**: 背景を軽くぼかし、ガラスの小さなパネル（12本のスピナー・題名・説明・細い進み具合）。パネルは少し縮んだ状態から開く |

ダークモードでも同じ形で表示する（読み込み中は保存データを読む前なので端末の設定に合わせる）。動きを減らす設定では光沢・開く動きを止め、スピナーだけをゆっくり回す。透明度を下げる設定ではガラスを不透明にする。
