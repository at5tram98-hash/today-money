## ACF指標

次の給料日までの「使えるお金 ÷ 予定支出」。

- 使えるお金 = 現在の預金 + 期間中の入金
- 予定支出 = 期間中の支払い（ホームの「次の支払い」と同じ予定）+ 最低残したい金額
- 1.0 で収支ちょうど0円、1.0未満は赤字、1.0以上は黒字（1.2未満は「ぎりぎり黒字」）
- 給料日が見つからない場合は30日間。日々の生活費は含めない

## 名称

ATF・生活費の見通しの表示名はすべて「ACF」に統一（内部の関数名・保存キーは変更なし）。
