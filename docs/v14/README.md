## 構成（指示書「最優先の決定事項」1〜7）

| 指示 | 実装 |
|---|---|
| 1. 5タブ→3タブ | 下部タブは「ホーム／支払い／その他」。給与・資産・今日の支出・今月の支出・請求一覧は**専用画面**（`DETAIL_SCREENS`、`src/js/07-navigation.js`）。どのrootから開いても同じ画面で、上部の「‹ 起点」で開いたrootへ表示位置ごと戻る。下部タブは起点のrootを選択状態のまま表示する |
| 2. ホーム上段のカード | 支出（今日／今月の切替・日付・時間帯／日別の棒グラフ・目標の状態）→総資産（ドーナツ・更新時刻）→今月の給与（6か月の棒グラフ・次の給料日）→生活費の見通し（30日の折れ線・安全残高の点線）→次の支払い。警告はある時だけ最上部（×で閉じても一覧に残る） |
| 3. 旧機能は削除せずコンパクトな表へ | 「最近の動き」: カテゴリ別支出（3行＋すべて見る）・最近の取引（3行＋すべての取引）・日締め・今月の比較・未確認の明細／大型支出／旅行・プレゼント（ある時だけ）・表示する項目の編集。旧「今日」「今月」画面の全機能は支出カードから開く専用画面に残る |
| 4. ＋入力ハブ | 右下の＋（52pt）から 支出を記録・臨時収入・残高を更新・給与を登録・その他の入力（請求額・再利用・一行入力・口座・勤務先・カード・デビット・固定支払い・大型支出・目標）。各画面に重複していた入力ボタン（旧「支出を記録」の大ボタン・クイック入力・各タブの補助ボタン）は撤去 |
| 5. カードの見た目 | 見出しはカードの外、左に金額、右に小型グラフ。不透明な白（ダークは濃灰）のカード。ガラス素材はタブバー・検索・今日／今月・＋などの操作層だけ |
| 6. 遷移は別管理 | [relocation.json](./relocation.json)（旧画面・旧入口→新しい入口）と transitions-85.csv。検査は3タブのrootから新しい入口を実際にタップしてたどる |
| 7. 設計IDは実DOMではない | ui-111.csv の「現行HTML ID・セレクタ」「ソースファイルと関数」に実際の要素を明記 |

## 主な変更ファイル

- `src/js/home-v14.js`（新規）: ホームのカードと表、＋入力ハブ、プロフィールパネル、日付カレンダー、表示項目の編集、支払いroot
- `src/js/07-navigation.js`: 3タブ（`switchRoot`）と専用画面（`DETAIL_SCREENS`・`placeDetailBack`）、メニューの補足行・プレビュー行・パネル表示
- `src/js/11-home-and-month.js`: 旧「今日」画面を専用画面「今日の支出」（`renderDay`、`#screen-day`）へ
- `src/js/settings.js`: 「その他」— 給与・資産・生活費の見通し・データとバックアップの2列タイル、システムのお知らせ
- `src/js/03-ledger.js`: 入出金予定の一覧 `financialEventsFrom`（ホームの次の支払い・支払いrootの次の引落）
- `src/index.html`: 3タブ、`#screen-day`・`#screen-payroot`、`#addHub`
- `src/css/home.css`・`navigation.css`・`layers.css`・`assets.css`・`forms.css`: 新しい部品。使われなくなった旧部品のCSSは削除

## 見つけて直した不具合

- 読み上げ層の監視（MutationObserver）とタブ表示の同期が互いを呼び続け、画面が固まる不具合を、作業中に検出して防止（状態の同期はクラスが変わる時だけ変更を起こす）。
