# Today Money

GitHub Pages で動く My Money 3.0。既存の機能、画面、保存キー、データ形式を引き継いでいます。

## My Time共通UIとACF修正

共通色・余白・ガラス素材・安全領域は `src/css/tokens.css` に集約しています。My Timeに合わせた上部の丸い操作ボタン、62pxの浮遊タブ、丸い主ボタン、数値の書体を使用します。タブは横へ滑らせて選択でき、離したときだけ切り替えます。縦移動・キャンセルでは切り替えません。透明度・コントラスト・動きを減らす設定にも対応します。

ACFは軽量試算と詳細計算のキャッシュを区別し、任意の予算期間・検討中の支出を含む計算を通常の予測と混在させません。分割払いは最終回の引落日まで確認し、設定保存時には開いている予測画面も更新します。設定プレビューと購入前比較では残高・日別予算が同一の軽量計算を使います。購入前比較は今日から180日以内を対象にし、購入日・カード引落日を共通の比較期間へ含めます。

`tests/acf-regressions.test.mjs` と `tests/ui-update-browser.mjs` で再発を検証します。後者はiPhone 15 Pro相当の393×852、タッチ、ライト／ダーク、ACF設定保存、タブのスライドとキャンセルを含みます。iOS実機のSafari・OSへのPush到達・認証を伴うGmail操作は別途実機確認が必要です。

## ファイル構成

- `src/index.html`: 画面の土台。
- `src/css/`: 基本スタイル、フォーム、ナビゲーション、ダッシュボード、明細、操作画面。
- `src/js/`: データモデル、保存、家計計算、ACF、給与、支払い、ATF、資産、Gmail、明細取込、操作補助。
- `src/js/settings.js` / `src/css/settings.css`: 設定一覧とプロフィール編集の統合コンポーネント。
- `src/manifest.json`: ビルド時の結合順序。
- `src/bootstrap-open.txt` / `src/bootstrap-close.txt`: 元の非同期起動処理の開始・終了。
- `assets/`: 公開用の生成済み JavaScript / CSS。
- `scripts/` / `tests/`: 再現可能なビルドと検証。

JavaScript は既存の関数の参照範囲と実行順序を保つため、編集元を機能ごとに分割し、公開時に同じ順序で結合します。各ファイルを個別に `<script>` で読み込む方式にはしないでください。既存の非同期起動処理の中で共有される変数と関数を維持するためです。CSS の優先順位も元の順序を維持します。

## 開発と公開

Node.js 24 以上を使用します。

```sh
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:browser
```

変更するファイルは `src/`、ビルド後に `index.html` と `assets/` を一緒にコミットします。GitHub Pages は既存の main ブランチの公開方法を使用します。生成ファイルの内容ハッシュをファイル名に含め、更新時の旧キャッシュとの混在を防ぎます。

## 互換性を保つ不具合修正

給与日が未設定の旧データを読み込む際の給与日計算関数の参照範囲、デビットで支払う大型支出の読み込み時の口座解決、月表示メニューの分析ボタンの対象月参照を修正しています。保存データのバージョン、各種キー、既存の計算式は変更していません。

## 設定画面と通知

全タブのサイドバー、関連するDOM・CSS・ジェスチャー・アクセシビリティ処理を削除しました。今日/今月の切り替えはホーム上部にあり、お気に入り・タグは設定から開けます。保存済みのお気に入りのキーは互換性のため維持しています。

システムからのお知らせは、日本時間（Asia/Tokyo）の今日を残し、昨日以前を削除します。読み込み・バックアップ復元時、画面への復帰時、開いたままなら1分ごとの保守処理で削除を保存します。ユーザー由来と明示された記録や日付を判定できない記録は削除対象にしません。自動削除後も現在の日付に対する新しいお知らせは生成します。

設定をグループ式の行と丸いプロフィール写真に変更しました。写真の変更・削除は保存するまで下書きとし、キャンセルできます。Web配布の許諾を確認できていないApple SF Symbolsは含めず、アプリのSVGを使用しています。変更箇所はプロフィールの円形表示、設定行の矢印、お気に入り・タグ・操作フィードバック、お知らせ一覧の警告/ベルです。iPhoneで写真選択を開いた際の操作画面はOSの標準ファイル選択を使用します。

Pro分析機能の提案は `PRO-PROPOSALS.md` にまとめています。

## 金額入力・日締め・通知基盤

新しい電卓、給与/支払いの共通月ダイヤル、7段階の照合・収入と支出の追加/編集・7日間の日締めジャーナルを統合しています。ATF/ACFの計算中表示は処理と描画の完了を待ちます。設計と理由は`FEATURE-DESIGN.md`。Cloudflareの通知用D1・Secret・Worker・Cronを本番接続し、`push-config.json`に公開URLと公開鍵を設定しています。端末では「設定→通知設定」で同期に同意し、通知を許可して接続します。OSへの通知到達は端末の許可後に確認します。運用手順は`worker/README.md`。

通知は接続コード不要の端末到達確認、購読の自動復旧、Service Worker更新後の認証維持に対応しています。`npm run push:deploy`は認証済みCloudflareで既存D1・Secret・配信URLを再利用します。通常のPages更新後も、独立した通知サーバーは稼働を続けます。Cloudflare BuildsをGitHubのmainへ接続し、対象ファイルの更新から自動検証・配備が成功することを確認しました。Node.js 24でビルド・静的検証・Workers実行検証の成功後、既存D1・鍵・URLを維持して配備します。GitHub Actionsの代替配備は停止したままで、二重配備しません。

## 表示切替と連続更新

ACFは表とカレンダーの表示切替、日締めは承認済みの閲覧と明示的な修正、当日目標は全体予算のスライダー／電卓入力に対応。給与・支払い・銀行残高の「金額を更新」は共通一覧から既存の編集と保存へ接続し、繰り返し更新できます。ATF/ACFの待機は最低1.8秒と描画完了を待ちます。計算・台帳・保存キー・Gmail解析・明細照合・通知接続は引き継いでいます。
